# Python Data Analytics Portfolio

Welcome to my Python analytics workspace! As an MSc IT graduate, this repository contains production-level data engineering routines, automated data cleansing arrays, and programmatic transformations built using Jupyter Notebooks.

## 🛠️ Tech Stack & Libraries Demonstrated
- **Environment:** Jupyter Notebook / Anaconda
- **Core Engine:** Python 3
- **Data Manipulation:** **Pandas** (DataFrames, Series, File Ingestion)
- **Numerical Operations:** **NumPy** (Vectorized math, Handling missing arrays)
- **Visualization: Used different charts with different theme using matplotlib and seaborn
- **EDA: Done EDA and found outliers trimmed it using different outlier methods

## 📂 Featured Project: World Population Data Cleansing Pipeline
- **Objective:** Engineered an automated Python script to ingest, clean, and standardize an unformatted corporate dataset, preparing it for downstream business intelligence workflows.
- **Core Operations Coded:**
  - **Duplicate Remediation:** Identified and stripped out redundant entity rows dynamically.
  - **Text Standardization:** Utilized advanced string filtering routines (`.str.strip`, text splits) to fix structural formatting anomalies and string spelling typos.
  - **Handling Missing Values:** Implemented programmatic mapping protocols to identify empty parameters and treat `NaN` / `NULL` blocks accurately.
  - **Schema Optimization:** Repaired broken index layers and dropped unhelpful data attributes to decrease structural memory overhead.
